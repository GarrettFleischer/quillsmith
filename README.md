# Quillsmith

Local-first novel writing app: Overview planning (acts → chapters → beats) and Write mode (scenes under chapters), knowledge base, scene revisions, OpenRouter tool-calling loops.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Add your OpenRouter API key in **Settings**.

SQLite database: `data/quillsmith.db` (gitignored).
