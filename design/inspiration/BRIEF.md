# Quillsmith aesthetic brief

## Locked direction: Ink Ledger

Calm manuscript workspace. Editorial craft chrome, not SaaS marketing. Dense-but-readable tool panels beside a quiet writing column.

## Feel

- Ink on paper / charcoal desk
- Ledger side rails (beats, KB) that feel like working notes
- Monumental brand mark in chrome: **Quillsmith**
- Weight in motion: soft fade/slide on panel reveals, never bounce candy

## Typography

- Display / brand: **"Fraunces"** (soft serif, expressive)
- UI chrome: **"Source Serif 4"** for manuscript; **"IBM Plex Sans"** for sidebars/controls
- Never Inter, Roboto, Arial, system-ui as display

## Guardrails (anti-slop)

- No purple / indigo gradients
- No warm cream + terracotta + Inter default stack
- No 3D SaaS blobs, glassmorphism stacks, glow orbs
- No card soup in writing surface
- No rounded-full pill clusters for primary nav
- Brand name must read as hero-level in app chrome, not a tiny nav whisper

## Inspiration families (explored → pick)

1. **Ink Ledger** — chosen
2. Quiet Charcoal — too dark-mode default; discarded as primary
3. Paper Craft — too close to cream/terracotta cliché
4. Dither Mono — too experimental for long writing sessions
5. Print Tech — strong for landing; wrong density for editor chrome

## Layout variants under Ink Ledger

- **A Wide rail**: 280px KB / fluid manuscript / 260px beats — chosen
- B Narrow chrome: too cramped for KB detail
- C Floating panels: too dashboard-like
